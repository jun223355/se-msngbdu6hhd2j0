유형별 암기법 — 무턱대고 외우지 않는 법

문제마다 유형이 있다. 유형을 알면 "어떻게 외울지"가 정해진다.

공통 엔진 — 백지 테스트 (○△✕)
① 문제집에서 답을 손으로 가리고 문제만 본다 → ② 빈 종이에 기억나는 대로 꺼내 쓴다 → ③ 답과 대조해 채점한다.
○ 다 맞음 = 졸업, 다시 안 봄 / △ 항목은 맞고 숫자·조건 틀림 = 이틀 뒤 다시 / ✕ 항목 자체를 빠뜨림 = 내일 다시.
※ 눈으로 읽기만 하는 건 암기가 아니다. 손으로 꺼내 써봐야 외워진다. ○ 나온 건 미련 없이 버려라 — 복습량이 매일 반으로 준다.

① 숫자형 — 값을 외우는 문제

예: Q1 교육시간(16·16·8·2) / 굴착면 기울기(1:1.8·1.0·0.5·1.2) / 조도(75·150·300·750) / 산소농도 18~23.5% / 안전난간 90~120cm / 측압 요인
  1. 같은 값끼리 쌍둥이로 묶기 — 감독교육 16 = 특별교육 16 → "16 쌍둥이".
  2. 규칙·리듬 찾기 — 조도는 막내 75에서 ×2씩(75→150→300→750). 숫자 4개를 따로 외우지 말고 규칙 1개로.
  3. 한 줄 주문으로 — "감독·특별 16, 채용 8, 변경 2".
함정 단위(m·㎡·럭스)와 이상/이하/미만을 반드시 붙여 쓴다. 숫자만 맞고 "이상" 빠뜨리면 감점.

② 나열형 — 항목을 N개 쓰는 문제

예: Q2 유해위험방지 대상(높·다·굴·터) / 비계 종류 / 개구부 방호 / 총괄책임자 직무 / 흙막이 붕괴현상 / 자율안전확인 10종
  1. "몇 개"부터 — "4가지 쓰시오"면 백지에 번호칸 4개부터 긋는다. 개수를 아는 게 절반.
  2. 두문자(앞글자)로 단어 만들기 — 높이·다리·굴착·터널 → "높다굴터" / 자율안전확인 → "연로한 혼파식 컨리공, 목인".
  3. 항목 먼저, 숫자 나중 — 항목을 다 떠올린 뒤 각 항목에 조건을 붙인다(높31·다리50·굴10·터널무조건).
함정 개수를 딱 맞게. 5가지 물으면 5개, 넘치게 쓰면 감점되는 경우 있음. 엉뚱한 항목(작업계획서 내용 등) 섞지 말 것.

③ 순서·절차형 — 단계를 순서대로 쓰는 문제

예: 위험성평가 순서 / 재해조사 순서 / 하인리히 예방 5단계 / 도미노 5단계 / 동바리 조립순서
  1. 앞글자 잇기 — 위험성평가: 준비→파악→추정→결정→대책→기록 = "준·파·추·결·대·기".
  2. "앞이 있어야 뒤가 된다" 인과로 — 조직 없으면 못 찾고, 못 찾으면 못 풀고, 못 고르면 못 고친다. 흐름을 이야기로 잡으면 순서가 안 꼬인다.
  3. 화살표로 그려서 — 단어 나열이 아니라 →로 이어 그린다.
함정 순서 뒤바꿈이 최다 출제. 특히 예방 5단계(조직부터) ↔ 도미노(환경부터) 헷갈림 주의.

④ 계산형 — 공식에 넣어 답을 내는 문제

예: 도수율·강도율·연천인율 / 종합재해지수 / 환산도수·강도율 / 지게차 안정도
  1. 공식은 "분자 / 분모 × 곱수"로 — 도수율=건수/시간×100만, 강도율=손실일수/시간×1,000. 이름에 곱수가 숨음(연천인율=천, 만인율=만).
  2. 부속값 세트 암기 — 사망=7,500일 / 휴업일수 ×300÷365 / 평생 근로=10만 시간. 이게 없으면 공식 알아도 못 푼다.
  3. 손으로 2~3번 직접 계산 — 눈으로 보면 시험장에서 막힌다.
함정 과정과 단위를 다 써야 점수. 답만 쓰면 감점. Safe T Score는 값이 클수록 나쁨(방향 주의).

⑤ 서술·인과형 — 이유·원리를 설명하는 문제

예: 하인리히 인과 / 흙막이 붕괴 원리(히빙·보일링) / 흙막이 공법 분류 / 각종 "~설명하시오"
  1. 통암기 대신 "왜 그렇게 되나" 한 줄 그림 — 히빙=배면 흙 무게가 벽 밑으로 돌아 들어와 바닥을 밀어올림. 원리 하나면 문장은 저절로 나온다.
  2. 원인 → 결과 화살표로 — 수위차 → 모래+물 분출(보일링). 그림카드 6장을 같이 본다.
  3. 키워드만 빈칸 없이 — 서술형은 부분점수. 완벽한 문장 못 써도 핵심 단어는 다 넣는다.
함정 외운 문장을 그대로 못 쓰면 0점이 아니다. 키워드라도 쓰면 점수가 있으니 빈칸으로 두지 말 것.
